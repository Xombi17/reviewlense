# ReviewLens AI — ROADMAP.md

> **GSD Roadmap** | Milestone 1.0 | Last updated: 2026-06-06

## Overview

Full-stack sentiment analysis web application. Classical ML pipeline (NB, LR, LinearSVM) with FastAPI backend and Next.js frontend. Built as an academic mini-project demonstrating end-to-end ML deployment.

## Phases

- [x] **Phase 1: Scaffolding & Setup** - Initialize repo structure, Python venv, deps, Next.js app
- [x] **Phase 2: Dataset & EDA** - Download Amazon reviews dataset, EDA notebook, cleaned CSV
- [x] **Phase 3: ML Training** - Train 3 classifiers, evaluation, model persistence, stats.json
- [x] **Phase 4: FastAPI ML Layer** - Model loader, predictor, aspect extraction, trust score
- [x] **Phase 5: FastAPI Endpoints** - /predict, /batch, /stats endpoints with Pydantic schemas
- [x] **Phase 6: Next.js Foundation** - Root layout, Navbar, TypeScript types, API client
- [x] **Phase 7: Analyzer Page** - Primary demo page with all result components
- [x] **Phase 8: Dashboard Page** - Model performance and dataset overview page
- [x] **Phase 9: Batch Analysis Page** - CSV upload page with drag-and-drop and results
- [x] **Phase 10: Integration & Polish** - E2E testing, error states, README, demo-ready (completed 2026-06-06)

**Success Criteria** (what must be TRUE):
  1. `from ml.predictor import predict; predict("battery life is amazing", "lr")` returns correct shape with `{sentiment, confidence, reliability, flags}`

  3. `from ml.trust import compute_trust_score; compute_trust_score("GREAT!!!!")` returns score < 0.8
